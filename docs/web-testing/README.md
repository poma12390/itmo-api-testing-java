Проверил приложение задач из второй лабораторной через Swagger UI и HTTP.
Составил 102 проверки, выполнил 99 и нашёл три бага. Требования взял из README
и OpenAPI версии `5c663ea7eadbbd830f438680f556f13639cfaecc`.

## Подготовка

Проверка от 17.10.2026: macOS 26.7.1, JDK 25.0.2, встроенный браузер Codex,
окно 1280×720. Приложение — Tasks API 1.0.0 на Spring Boot 3.5.16.
Остальные сведения о запуске — в [environment.json](evidence/environment.json).

```bash
./mvnw -DskipTests package
java -jar target/api-testing-lab2-1.0.0.jar \
  --server.address=127.0.0.1 --server.port=18080
```

Открыть `http://127.0.0.1:18080/swagger-ui/index.html`. Нужен JDK 21 или 25.

Проверял отдельный экземпляр приложения. Между сценариями удалял тестовые
задачи; для пагинации создал 21 задачу в известном порядке. ID брал из ответа
POST. Основной CRUD-сценарий и каждый баг проверил через браузер, остальные
границы и повреждённые данные — HTTP-запросами.

Шесть неудачных проверок относятся к трём багам:

| Баг | Что происходит | Пункты чек-листа |
| --- | --- | --- |
| [BUG-001](bugs/BUG-001.md) | Данные после первого JSON-объекта игнорируются, запрос меняет хранилище | JSON-05, JSON-06 |
| [BUG-002](bugs/BUG-002.md) | Сохраняется название из Unicode-пробела | TITLE-18, TITLE-19 |
| [BUG-003](bugs/BUG-003.md) | Отклоняется название из 51–100 emoji, допустимое по OpenAPI | TITLE-15, TITLE-16 |

Каждый баг повторил три раза на POST и три раза на PUT. Все три пока открыты.
Не выполнял проверки в отдельных Chrome и Firefox, на мобильном экране и только
с клавиатуры — они отмечены Not run.

Создание, чтение, изменение и удаление работают. В первую очередь стоит исправить
BUG-001: повреждённый запрос может заменить существующую задачу. Затем — привести
правила обработки Unicode в коде и контракте к одному варианту. После исправлений
нужно повторить связанные проверки и основной CRUD-сценарий.
