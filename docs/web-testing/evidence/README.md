# Материалы проверки

Прогон от 17.10.2026, версия `5c663ea7eadbbd830f438680f556f13639cfaecc`.
Запросы выполнялись на отдельном локальном экземпляре с тестовыми задачами.

| Файл | Что подтверждает |
| --- | --- |
| [environment.json](environment.json) | Версию, окружение, команду запуска и SHA-256 проверенного JAR |
| [openapi-observed.json](openapi-observed.json) | Контракт, полученный с работающего сервера; сравнение с файлом проекта — HTTP-01 |
| [http-checks.json](http-checks.json) | 85 пунктов и фактические HTTP-события, включая подготовку, чтение до/после и очистку |
| [defect-repeats.json](defect-repeats.json) | 18 повторов: 3 дефекта × 2 метода × 3 попытки |
| [ui-checks.json](ui-checks.json) | 13 проверок в веб-интерфейсе и ссылки на текстовые снимки |
| [lifecycle.json](lifecycle.json) | Наличие задач до перезапуска и пустое хранилище после него |
| [checklist-results.json](checklist-results.json) | Все 102 пункта и итоговые счётчики |
| [reproduce-BUG-001.txt](reproduce-BUG-001.txt), [BUG-002](reproduce-BUG-002.txt), [BUG-003](reproduce-BUG-003.txt) | Фактический вывод готовых команд воспроизведения для обоих методов |

В `http-checks.json` поле `checks` связывает пункт чек-листа с событиями
`events` через `eventRange`. Индексы начинаются с нуля, обе границы включены.
Диапазон содержит также подготовку данных, чтение и очистку.

В `defect-repeats.json` повторы можно найти по `bug`, `method` и `attempt`.
Счётчики в `metadata.summary` относятся к основному прогону.

Текстовые снимки `ui/*.txt` содержат и фактический **Server response**,
и справочные **Responses**. HTTP-журналы сохраняют запросы и ответы; в выводе
curl убраны пробелы в конце строк и приведены к одному виду окончания строк.
