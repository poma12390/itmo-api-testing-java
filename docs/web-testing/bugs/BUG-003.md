# BUG-003. Название из 51–100 emoji отклоняется

| Поле | Значение |
| --- | --- |
| Статус | New |
| Методы | POST `/tasks`, PUT `/tasks/{taskId}` |
| Severity / Priority | S2 Major / P2 — допустимое по контракту название нельзя сохранить |
| Повторяемость | 51 × U+1F600: POST 3/3, PUT 3/3; также в Swagger UI |
| Проверки | TITLE-15, TITLE-16; R-06 |

Версия и окружение — в [отчёте](../README.md). В OpenAPI длина title — от 1 до 100.
Для PUT нужна существующая задача.

## Шаги

1. Скопировать тело из [файла с 51 emoji](../fixtures/bug-003-emoji-51.json).
2. В Swagger UI раскрыть POST `/tasks`, нажать **Try it out**, вставить тело и выполнить запрос.
3. Повторить через PUT для существующей задачи.
4. Прочитать список и исходную задачу, чтобы проверить сохранённые данные.

```bash
curl -i -X POST http://127.0.0.1:18080/tasks \
  -H 'Content-Type: application/json' \
  --data-binary @docs/web-testing/fixtures/bug-003-emoji-51.json
```

## Ожидание и результат

Ожидал **201** на POST и **200** на PUT: 51 кодовая точка укладывается в
`maxLength=100` по [JSON Schema](https://json-schema.org/draft/2020-12/json-schema-validation#section-6.3.1).
Получил **422** на обоих методах, данные не изменились:

```json
{"detail":"Validation failed","field":"title"}
```

Контрольные значения:

| Название | Кодовые точки | Единицы UTF-16 | POST / PUT | Оценка |
| --- | ---: | ---: | --- | --- |
| 50 × U+1F600 | 50 | 100 | 201 / 200 | Корректно |
| 51 × U+1F600 | 51 | 102 | 422 / 422 | Дефект |
| 100 × U+1F600 | 100 | 200 | 422 / 422 | Дефект |
| 101 × U+1F600 | 101 | 202 | 422 / 422 | Корректно |
| 100 × «я» | 100 | 100 | 201 / 200 | Корректно |
| 101 × «я» | 101 | 101 | 422 / 422 | Корректно |

Каждый emoji — одиночный U+1F600 без модификаторов. Он занимает две единицы
UTF-16. Похоже, `@Size(max=100)` считает именно их: 50 emoji проходят,
а 51 уже нет.

## Повторная проверка

50, 51 и 100 emoji должны приниматься на POST и PUT, 101 — давать 422 без
изменения данных. Также нужно проверить смесь кириллицы и emoji.
