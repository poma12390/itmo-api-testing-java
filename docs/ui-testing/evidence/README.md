# Доказательства прогона UI-автотестов

Проверка выполнена 18.10.2026, Europe/Samara (UTC+04:00), на JDK 25.0.2,
macOS 26.7.1 aarch64 и Chromium 153.0.8010.12. Все пять UI-тестов и 95 API-тестов
прошли без ошибок и пропусков. Приложение поднято автоматически на свободном
локальном порту. Все файлы относятся к одному заключительному прогону.

Команда из корня проекта после установки зависимостей и Chromium:

```bash
MAVEN_USER_HOME="$PWD/.m2" ./mvnw -o -B --no-transfer-progress -Pui clean verify
```

| Файл | Что подтверждает |
| --- | --- |
| [verify.txt](verify.txt) | Фактический журнал: 95 API-тестов, 5 UI-тестов, проверка покрытия, BUILD SUCCESS |
| [junit.xml](junit.xml) | Все 100 тестовых случаев с именами, длительностью и результатом |
| [environment.json](environment.json) | Окружение, время, реальная версия браузера, размер окна и временный адрес приложения |
| [ui-results.json](ui-results.json) | Статусы и JSON из блоков Server response в финальном HTML каждого сценария |
| [run-summary.json](run-summary.json) | Сводка, покрытие, базовый коммит, SHA-256 исходников, JAR и файлов доказательств |

`junit.xml` собран из XML-отчётов Surefire и Failsafe. Сохранены атрибуты наборов
и тестовых случаев; удалены системные свойства JVM и текстовые потоки, чтобы
не дублировать окружение и журнал. Исходные отчёты доступны после запуска
в `target/surefire-reports/` и `target/failsafe-reports/`.

`ui-results.json` получен из сохранённого `page.html`, а не прямыми запросами
к API. В нём записаны только последние видимые ответы каждой операции.
Например, в UI-04 итоговый DELETE показывает 404 после повторного удаления;
промежуточный ответ 204 проверяется самим тестом и доступен в локальной трассировке.
После перезагрузки страницы история ранее выполненных операций пропадает
из DOM, поэтому UI-01 и UI-03 показывают финальное чтение и список.

## Скриншоты

| Сценарий | Финальное состояние |
| --- | --- |
| UI-01 | [Созданная задача после перезагрузки и в списке](ui/createsAndReadsTaskAfterReload.png) |
| UI-02 | [100 символов в названии и значения по умолчанию](ui/appliesDefaultsToTaskWithMaximumTitleLength.png) |
| UI-03 | [Изменённая задача после перезагрузки](ui/replacesTaskAndPersistsChanges.png) |
| UI-04 | [Ошибка 404 после удаления и пустой список](ui/deletesTaskAndShowsNotFound.png) |
| UI-05 | [Ошибки title/priority и сохранённая контрольная задача](ui/rejectsInvalidInputWithoutChangingStoredTask.png) |

Скриншоты сделаны автоматически в `@AfterEach`, до закрытия контекста браузера.
Полные HTML-снимки и `trace.zip` каждого теста создаются в
`target/ui-artifacts/<имя метода>/`; они не включены в исходники. При повторном
прогоне порт и время могут отличаться; ID тесты получают из ответа создания.
Для проверки промежуточных действий
нужно открыть трассировку, как описано в [отчёте](../README.md#отчёты-и-дополнительные-улучшения).

В `run-summary.json` указан базовый коммит предыдущей работы. Версию новой
лабораторной дополнительно фиксируют SHA-256 файлов приложения, тестов,
контракта и конфигурации: новые изменения на момент прогона находятся
в рабочей копии ветки `codex/ui-testing`.

В `verify.txt` удалены пробелы в конце строк для корректного просмотра diff;
сообщения Maven, результаты и время прогона сохранены.
